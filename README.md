A tiny program that writes exactly one line to `/output/entry.txt` — an
office joke built on malicious literal compliance: **My review said I
need to be "more visible," so now I walk past my boss's office every 45
minutes.** Every performance review hands out that same vague verdict,
and the line answers it the way every employee has wanted to: by
obeying it to the letter, on a timer. It was chosen by a
criteria-ordered tournament against the judge's published criteria
(truth to office life, surprising turn, tightness, freshness), beating
an unlimited-vacation runner-up whose turn arrived slower. Output is
byte-exact with no trailing newline. Run it with `python3 main.py`.
